# Lekcia 02: Prvy Go program

## Ciel

Vediet spustit Go program a rozumiet funkcii `main`.

## Co si vysvetlime

- balicek `main`
- funkcia `main()`
- importy
- prikaz `go run`

## Uloha

V subore `cmd/tunneler/main.go` zmen text, ktory server vypise pri starte, a program znovu spusti.
