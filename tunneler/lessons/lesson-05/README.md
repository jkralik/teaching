# Lekcia 05: HTML klient

## Ciel

Rozumiet, co robi `index.html`.

## Co si vysvetlime

- zakladne HTML tagy
- formularove prvky `input`, `select`, `button`
- element `canvas`
- prepojenie HTML, CSS a JavaScriptu

## Kodovy krok

V `web/index.html` pridaj do ovladacieho panela element `<span id="server-message"></span>`. V `web/app.js` ho po nacitani stranky napln textom `Pripravene na hru`.

Novy pojem: DOM element ma `id`, cez ktore ho JavaScript najde pomocou `document.getElementById` a zmeni jeho `textContent`.

## Overenie

Obnov stranku a skontroluj, ze sa sprava zobrazi v ovladacom paneli bez zmeny servera.

## Uloha

Uprav titulok stranky a text tlacidla na pripojenie.

## Mini vyzva

Pridaj dalsi element s menom hraca a zobraz v nom hodnotu z textoveho pola.
